# Logistics Truck Route Visualizer

A frontend app that simulates a truck moving through delivery locations, built with React, TypeScript, Zustand and Leaflet.

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` start the dev server
- `npm run build` typecheck and build for production
- `npm test` run the unit tests
- `npm run lint` lint the project

More detail on architecture and decisions is added as the project builds out.
